# Pinal County Roleplay Website

Official website for Pinal County Roleplay (PCRP) community.

**Discord:** [Discord.gg/pcrp](https://discord.gg/pcrp)

## Overview

This is a professional website for the Pinal County Roleplay server, featuring information about the community, server rules, and application process.

## Features

- 🏠 **Hero Section** - Eye-catching landing page
- ℹ️ **About Section** - Community information and features
- 📋 **Rules Section** - Server rules and guidelines
- 📝 **Application Section** - Join the server
- 📬 **Contact Form** - Get in touch with the team
- 📱 **Fully Responsive** - Works on all devices

## Pages Included

- `index.html` - Main homepage with all sections
- `styles.css` - Professional styling with animations

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Customize colors, text, and content as needed

## Customization

Edit `styles.css` to change colors:
- Primary Color: `#1a472a` (dark green)
- Secondary Color: `#2d7a4a` (medium green)
- Accent Color: `#f39c12` (orange)
